# คู่มือการใช้งาน Branch `fea/test-data/post`
## SHARE-ED: สื่อการเรียนรู้และระบบสร้าง/ลบโพสต์อัตโนมัติ (Playwright)

เอกสารฉบับนี้จัดทำขึ้นสำหรับ Branch **`fea/test-data/post`** โดยเฉพาะ เพื่อใช้สร้างข้อมูลโพสต์สื่อการเรียนรู้จริงเข้าสู่เว็บไซต์ [SHARE-ED](https://share-ed.online/) จำนวน **6 โพสต์** ครอบคลุมสาระการเรียนรู้สำคัญ พร้อมทั้งภาพปก AI คุณภาพสูง, การจัดย่อหน้าเว้นวรรคบรรทัดสวยงาม, รูปภาพแกลเลอรี, ไฟล์เอกสาร PDF, และระบบสั่งลบข้อมูล (Cleanup) อัตโนมัติ

---

## 📌 วัตถุประสงค์ของ Branch นี้

1. **สร้างข้อมูลสื่อการเรียนรู้จริง 6 หัวข้อ**: นำเข้าโพสต์เนื้อหาการเรียนรู้จริงเข้าสู่แพลตฟอร์ม ครอบคลุม ม.ต้น, ม.ปลาย และมหาวิทยาลัย
2. **สร้างสื่อการเรียนรู้คุณภาพสูง**:
   - **รูปหน้าปก AI (Cover PNG)** ขนาด **1280 x 720** พิกเซล ไม่เกิน 2 MB
   - **รูปภาพประกอบ (Gallery Images)** ขนาด **1080 x 1080** พิกเซล จำนวน 3 รูปต่อโพสต์
   - **เอกสารประกอบการเรียนรู้ PDF** ขนาด A4 จัดหน้าสรุปเนื้อหาจริง
   - **การจัดย่อหน้าเนื้อหา (Rich Text)** เว้นวรรคบรรทัดอ่านง่าย สบายตา
3. **ระบบจัดการโพสต์แบบยืดหยุ่น**: รองรับทั้งคำสั่ง **ลบโพสต์เดิมทิ้งแล้วโพสต์ใหม่ทันที**, **ลบโพสต์ทั้งหมด**, หรือ **ตรวจสอบโพสต์** ผ่านคำสั่งเดียว

## 🚀 ลำดับขั้นตอนและคำสั่งที่ต้องใช้งาน (Step-by-Step Commands)

### 🔹 ขั้นตอนที่ 1: เตรียมสภาพแวดล้อม (รันเฉพาะครั้งแรก)
ติดตั้ง Library และบราวเซอร์ Chromium:
```bash
npm install
npx playwright install chromium
```

---

### 🔹 ขั้นตอนที่ 2: บันทึกการเข้าสู่ระบบ (Login)
เข้าสู่ระบบเพื่อบันทึกสถานะการล็อกอิน (Session) เก็บไว้ในเครื่อง:
```bash
npm run login
```
*(ระบบจะล็อกอินและบันทึก Storage State ไว้ที่ `playwright/.auth/member.json`)*

---

### 🔹 ขั้นตอนที่ 3: เลือกคำสั่งตามรูปแบบที่ต้องการทำงาน

#### 🌟 แบบที่ 1: "ลบของเดิมทิ้ง แล้วสร้างโพสต์ใหม่ 6 โพสต์ทันที" (แนะนำสำหรับการอัปเดต)
คำสั่งนี้จะลบโพสต์เดิมที่เคยสร้างไว้ทั้งหมดออกก่อน จากนั้นอัปโหลดภาพปก AI ใหม่ จัดย่อหน้าเว้นวรรคบรรทัด และเผยแพร่โพสต์ใหม่ครบทั้ง 6 โพสต์ในรอบเดียว:
```bash
npm run post:recreate
```

#### 🗑️ แบบที่ 2: "ลบโพสต์ทั้งหมดทิ้งอย่างเดียว" (Cleanup)
หากต้องการเคลียร์โพสต์ที่สร้างไว้ออกจากเว็บไซต์:
```bash
npm run delete:posts
```
*(หรือระบุ URL เพื่อลบเฉพาะโพสต์: `node scripts/delete-all-posts.js <post-url>`)*

#### 📝 แบบที่ 3: "สร้างโพสต์ใหม่ทั้ง 6 โพสต์" (โดยไม่ลบของเก่า)
```bash
npm run post:publish
```

#### 🔍 แบบที่ 4: "ตรวจสอบโพสต์ทั้งหมดและบันทึกภาพหน้าจอ"
เข้าไปตรวจเช็กว่าทั้ง 6 โพสต์เปิดดูได้ตามปกติ ข้อมูลครบถ้วน และแคปภาพ Full-page เก็บในโฟลเดอร์ `reports/screenshots/`:
```bash
npm run post:verify
```

## 📚 รายการเนื้อหาทั้ง 6 โพสต์ในระบบ

1. **สมการเชิงเส้นตัวแปรเดียว: สรุปหลักการแก้สมการและโจทย์ปัญหา**  
   - ระดับ: มัธยมศึกษาตอนต้น | หมวด: คณิตศาสตร์ | แท็ก: `#สรุปย่อ`, `#คณิต`, `#สมการ`
2. **ระบบสุริยะ: สรุปข้อมูลดาวเคราะห์และวัตถุท้องฟ้าในระบบสุริยะ**  
   - ระดับ: มัธยมศึกษาตอนต้น | หมวด: วิทยาศาสตร์ | แท็ก: `#จักรวาล`, `#อวกาศ`, `#วิทย์`
3. **12 Tenses ภาษาอังกฤษ: สรุปหลักการใช้ โครงสร้าง และตัวบอกเวลา**  
   - ระดับ: มัธยมศึกษาตอนปลาย | หมวด: ภาษาอังกฤษ | แท็ก: `#อังกฤษ`, `#Tense`, `#Grammar`
4. **กฎการเคลื่อนที่ของนิวตัน: สรุปแรง กลศาสตร์ และการเขียน FBD**  
   - ระดับ: มัธยมศึกษาตอนปลาย | หมวด: ฟิสิกส์ | แท็ก: `#ฟิสิกส์`, `#แรง`, `#นิวตัน`
5. **โครงสร้างเซลล์: สรุปหน้าที่ออร์แกเนลล์ เซลล์พืชและเซลล์สัตว์**  
   - ระดับ: มัธยมศึกษาตอนปลาย | หมวด: ชีววิทยา | แท็ก: `#สรุปย่อ`, `#ชีวะ`, `#เซลล์`
6. **Frontend Backend Database และ API: พื้นฐานสถาปัตยกรรมเว็บ**  
   - ระดับ: มหาวิทยาลัย | หมวด: คอมพิวเตอร์และเทคโนโลยี | แท็ก: `#Frontend`, `#WebDev`, `#Backend`

# คู่มือการใช้งาน Branch `fea/test-data/post`
## SHARE-ED: สื่อการเรียนรู้และระบบสร้าง/ลบโพสต์อัตโนมัติ (Playwright)

เอกสารฉบับนี้จัดทำขึ้นสำหรับ Branch **`fea/test-data/post`** โดยเฉพาะ เพื่อใช้สร้างข้อมูลโพสต์สื่อการเรียนรู้จริงเข้าสู่เว็บไซต์ [SHARE-ED](https://share-ed.online/) ให้พร้อมสำหรับการแสดงผลและการใช้งานจริง พร้อมทั้งระบบสั่งลบข้อมูล (Cleanup) เมื่อต้องการเคลียร์ข้อมูลออกจากระบบ

---

## 📌 วัตถุประสงค์ของ Branch นี้

1. **สร้างข้อมูลสื่อการเรียนรู้จริงบนเว็บไซต์**: นำเข้าโพสต์เนื้อหาการเรียนรู้ที่มีข้อมูลจริง ครอบคลุม 5 หมวดหมู่วิชาหลัก เพื่อให้หน้าเว็บมีเนื้อหาที่สมบูรณ์ สวยงาม และพร้อมใช้งาน
2. **สร้างสื่อการเรียนรู้คุณภาพสูงอัตโนมัติ**: 
   - **รูปหน้าปก (Cover Image)** ขนาด **1280 x 720** พิกเซล ไม่เกิน 2 MB
   - **รูปภาพประกอบ (Gallery Images)** ขนาด **1080 x 1080** พิกเซล จำนวน 3 รูปต่อวิชา ไม่เกิน 2 MB
   - **เอกสารประกอบการเรียนรู้ PDF** ขนาด A4 จัดหน้าสรุปเนื้อหาจริง ไม่เกิน 20 MB
3. **ระบบจัดการโพสต์แบบยืดหยุ่น**: สามารถเลือกสั่ง **สร้างโพสต์ทั้งหมด** หรือสั่ง **ลบโพสต์ทั้งหมด** ได้อย่างสะดวกรวดเร็วผ่านคำสั่งเดียว

## 🚀 สรุปคำสั่งการใช้งานด่วน (Quick Commands)

| คำสั่ง | คำอธิบายการทำงาน |
|---|---|
| `npm run generate:media` | เจเนอเรตรูปภาพ Cover (1280x720), รูปภาพประกอบ (Gallery), และไฟล์ PDF ทั้งหมดใหม่ |
| `npm run create:posts` | รัน Playwright เพื่อสร้างโพสต์สื่อการเรียนรู้จริงทั้ง 5 วิชาขึ้นสู่เว็บไซต์ (คงโพสต์ไว้ ไม่ลบ) |
| `npm run delete:posts` | รัน Playwright เพื่อสั่งลบโพสต์สื่อการเรียนรู้ทั้งหมดที่สร้างไว้ออกจากระบบ (Cleanup) |
| `npm run test:ui` | เปิด Playwright Interactive UI เพื่อเลือกดูหน้าจอหรือกดรันทีละเคส |
| `npm test` | สั่งรันชุดทดสอบทั้งหมดตามการตั้งค่าของ Playwright |

## 📖 คู่มือการใช้งานแต่ละคำสั่งอย่างละเอียด

### 1. สั่งสร้างโพสต์สื่อการเรียนรู้ขึ้นเว็บไซต์ (`npm run create:posts`)
คำสั่งนี้จะทำการเข้าสู่ระบบด้วยบัญชีสมาชิก และทำการโพสต์สื่อการเรียนรู้จริง 5 วิชาอย่างเป็นลำดับ โดยไม่ทำการลบโพสต์ทิ้ง:
```powershell
npm run create:posts
```

หากต้องการเปิดหน้าต่าง Browser ดูการทำงานแบบสดๆ (Headed Mode):
```powershell
npx playwright test tests/post/create-post.spec.js -g "สร้างโพสต์:" --project=chromium --headed
```

**รายการวิชาและเนื้อหาที่ถูกโพสต์:**
1. 📘 **คณิตศาสตร์ (มัธยมศึกษาตอนปลาย)**: *สรุปสูตร แคลคูลัส ม.ปลาย: ลิมิต อนุพันธ์ และปริพันธ์*
   - รูปหน้าปกสีน้ำเงิน/ม่วง (1280x720)
   - แผ่นสรุปสูตรดิฟ อินทิเกรต และจุดสูงสุด-ต่ำสุด 3 แผ่น
   - ไฟล์สรุปบทเรียน PDF: `handbook.pdf`
2. ⚡ **ฟิสิกส์ (มัธยมศึกษาตอนปลาย)**: *สรุปฟิสิกส์ ม.ปลาย: กฎการเคลื่อนที่และแรงของนิวตัน*
   - รูปหน้าปกสีฟ้า/น้ำเงิน (1280x720)
   - แผนภาพ 5 สูตรการเคลื่อนที่ กฎ 3 ข้อของนิวตัน และเทคนิคเขียน FBD
   - ไฟล์สรุปบทเรียน PDF: `handbook.pdf`
3. 🧬 **ชีววิทยา (มัธยมศึกษาตอนปลาย)**: *สรุปชีววิทยา: เซลล์และการแบ่งเซลล์ ไมโทซิส vs ไมโอซิส*
   - รูปหน้าปกสีเขียวมรกต (1280x720)
   - สรุปหน้าที่ออร์แกเนลล์ วัฏจักรเซลล์ และตารางเปรียบเทียบ Mitosis vs Meiosis
   - ไฟล์สรุปบทเรียน PDF: `handbook.pdf`
4. 💻 **คอมพิวเตอร์และเทคโนโลยี (มหาวิทยาลัย)**: *Data Structures & Algorithms พื้นฐานสำหรับผู้เริ่มต้น*
   - รูปหน้าปกสีม่วงเทคโนโลยี (1280x720)
   - สรุป Big-O Notation, Array vs Linked List, Stack vs Queue
   - ไฟล์สรุปบทเรียน PDF: `handbook.pdf`
5. 🇬🇧 **ภาษาอังกฤษ (มัธยมศึกษาตอนปลาย)**: *สรุป 12 Tenses ภาษาอังกฤษ ฉบับเข้าใจง่าย ใช้งานได้จริง*
   - รูปหน้าปกสีส้มไวยากรณ์ (1280x720)
   - ตารางสรุป 12 Tenses, Time Markers และเปรียบเทียบ Past Simple vs Present Perfect
   - ไฟล์สรุปบทเรียน PDF: `handbook.pdf`

### 2. สั่งลบโพสต์ทั้งหมดออกจากเว็บไซต์ (`npm run delete:posts`)
เมื่อต้องการเคลียร์โพสต์ที่สคริปต์เคยสร้างไว้ออกจากระบบ สามารถสั่งรันคำสั่งนี้ได้:
```powershell
npm run delete:posts
```

หากต้องการเปิดหน้าต่าง Browser ดูการลบทีละโพสต์แบบสดๆ (Headed Mode):
```powershell
npx playwright test tests/post/create-post.spec.js -g "ลบโพสต์" --project=chromium --headed
```

**สิ่งที่ระบบจะทำโดยอัตโนมัติ:**
1. ดึงรายการโพสต์ที่เป็นของผู้ใช้ปัจจุบันจากระบบ Backend
2. เดินทางไปยังหน้ารายละเอียดของแต่ละโพสต์ (`/post/:id`)
3. รอให้ปุ่มสีแดง **"ลบโพสต์"** แสดงขึ้นมาและคลิก
4. กดยืนยันในกล่องข้อความเตือนด้วยปุ่ม **"ใช่, ลบเลย"**
5. ตรวจสอบกล่องข้อความยืนยันลบสำเร็จและกดปุ่ม **"OK"**
6. วนลูปจนกระทั่งโพสต์ที่สร้างไว้ทั้งหมดถูกลบออกจากระบบอย่างสมบูรณ์

## 👤 การกำหนดบัญชีผู้ใช้งาน (User & Authentication)

ระบบกำหนดบัญชีผู้ใช้สำหรับการล็อกอินและสร้างโพสต์ไว้ที่ไฟล์ **`global-setup.js`**:

```javascript
// global-setup.js (บรรทัดที่ 17-18)
await page.getByRole('textbox', { name: 'อีเมล' }).fill('member01@test.com');
await page.getByRole('textbox', { name: 'รหัสผ่าน' }).fill('Test1234');
```

- เมื่อเริ่มรันเทส `globalSetup()` จะเข้าสู่ระบบและบันทึก Session ไว้ที่ `playwright/.auth/member.json`
- ทุกเคสใน `create-post.spec.js` จะใช้ Session นี้โดยอัตโนมัติ ทำให้ไม่ต้องพิมพ์รหัสผ่านใหม่ทุกครั้ง
- **หากเปลี่ยน User**: ให้แก้ไขอีเมล/รหัสผ่านใน `global-setup.js` และลบโฟลเดอร์ `playwright/.auth/` ออก เพื่อให้ระบบล็อกอินใหม่ในครั้งถัดไป
